# Juego de Combate por turnos.
Consiste en un juego por turnos inspirado en los libros y series de Game of thrones, en la cual puedes ser un caballero del universo mencionado, y te enfrentas a caballeros reconocidos.
Contiene un ranking, donde puedes competir contra otros usuarios y comparar tu puntuacion en un scoreboard. Además contiene una Ayuda para que puedas entender algunas mecanicas integradas dentro del juego.

##Requisitos
Java 21.
